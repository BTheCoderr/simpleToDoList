# Command Center Roadmap

This roadmap describes product direction, not guaranteed dates.

## Shipped

- Signal First daily workflow with 3–5 Must-Wins and a hard cap of 5
- Noise Parking Lot with promote / park controls
- Signal-first Focus Mode and tomorrow-Signal Daily Shutdown
- local-first IndexedDB workspace
- Inbox / Next / Doing / Done task workflow
- Smart Quick Add
- projects, goals, notes, habits, and subtasks
- recurring tasks
- saved views, filters, and bulk actions
- Month / Week / Day Planner
- Kanban Board
- Focus Mode
- customizable Signal dashboard
- Daily Shutdown and Weekly Review
- Analytics and Activity History
- Archive / Trash / Undo
- rotating recovery snapshots
- validated JSON backup/import
- CSV and Markdown exports
- optional local Privacy Lock
- installable PWA
- offline app shell and deep-link support
- Web Share Target
- controlled service-worker updates
- responsive browser QA down to 320px
- offline, stress, accessibility, PWA, and regression test coverage

## Improving

- real-device iPhone Add to Home Screen / offline verification
- accessibility and keyboard/screen-reader polish
- cross-browser PWA edge cases
- release screenshots and repository presentation
- performance and reliability as real usage grows
- documentation accuracy as the product evolves

## Exploring

- additional local-only import/export ergonomics
- better local search and navigation shortcuts
- optional workflow refinements driven by real usage

## Product boundary

Command Center should remain useful without an account, cloud database, or server dependency.

Cloud sync or multi-device accounts should not be added casually; they would change the product's privacy, reliability, cost, and architecture model.
